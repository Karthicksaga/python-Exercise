# Suggestions

Proposals, reviews and recommendations for Hop. These are things suggested, not things built. Once a suggestion is built, its record moves to the project docs (`hop-platform/docs/`, `hop-mobile-platform/docs/`), and the suggestion's "Progress" or "Status" line says so.

## How to add one

- One file per suggestion, named `YYYY-MM-DD-short-topic.md`.
- Start with the date, a status (Proposed, Accepted, In progress, Done, Rejected) and the scope.
- Then: a summary, evidence (file paths), the recommendation and open questions.
- Add a row to the index below, newest first.
