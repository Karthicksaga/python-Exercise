# Building Flickering & Z-Fighting Root Cause Analysis

**Scope:** Non-destructive diagnostic audit of `godot-chennai` (`Godot 4.7.2`, Mobile Forward+/Mobile renderer, Adreno 613 target GPU).

---

## 1. Root Causes Identified in Existing Codebase

### Cause 1 — Landmark 24 m LOD Overlap Zone (Severe)
- **File:** [landmark_models.gd](file:///Users/kjayap419@apac.comcast.com/Desktop/workspace/test_2/python-Exercise/godot-chennai/src/game_engine/city/landmark_models.gd#L17-L116)
- **Code:**
  ```gdscript
  const FADE := 12.0
  ...
  copy.visibility_range_begin = 0.0 if i == 0 else ends[i - 1]
  copy.visibility_range_begin_margin = 0.0 if i == 0 else FADE
  copy.visibility_range_end = ends[i]
  copy.visibility_range_end_margin = FADE if i < 2 else 0.0
  copy.visibility_range_fade_mode = GeometryInstance3D.VISIBILITY_RANGE_FADE_DISABLED
  ```
- **Why it flickers:** Setting `visibility_range_begin_margin = 12.0` and `visibility_range_end_margin = 12.0` with `VISIBILITY_RANGE_FADE_DISABLED` causes **`LOD0` and `LOD1`** (and `LOD1` and `LOD2`) to render simultaneously across a 24 m band around each transition distance. Because `LOD0` and `LOD1` share identical wall planes, the GPU depth buffer Z-fights rapidly across pixels whenever the camera approaches or leaves a landmark.
- **Recommended Fix (for integration stage):** Zero out overlap margins (`margin = 0.0`) when fade is disabled, or bias `LOD1` inward by `-0.04 m` if cross-fading is ever enabled.

### Cause 2 — Thin Wall Attachment Clearances on 16-bit Depth Buffers (Moderate–Severe)
- **File:** [building_meshes.gd](file:///Users/kjayap419@apac.comcast.com/Desktop/workspace/test_2/python-Exercise/godot-chennai/src/game_engine/city/building_meshes.gd#L52-L61)
- **Measurements:**
  - `SHUTTER_OFFSET := 0.06` (`6 cm` in front of wall quad at `d = 0.0`)
  - Signboard back face starts at `d0 = 0.01` (`SIGN_DEPTH := 0.14`)
  - Chajjas (`_add_chajja`) and balconies (`_add_balcony`) start at `d0 = 0.0`, while balcony railings sit at `top + 0.015` above the balcony deck (`BALCONY_DEPTH - 0.02`).
  - Adjacent OSM row houses share zero-gap wall planes on dense streets (George Town, Triplicane, North Chennai).
- **Why it flickers:** On mobile forward/mobile renderers at 120–250 m view distances, `0.01–0.06 m` falls below depth-buffer precision, causing shutters, sign backs, balcony decks, and shared walls to shimmer.
- **Pack 100 Design Fix:** All 100 `.glb` models generated by `tools/buildings/build_pack_100.py` maintain `>= 0.06–0.12 m` outward separation, omit hidden interior back faces on surface-mounted signs/shutters, and use outward CCW winding (`CULL_BACK`) instead of double-sided draws.

### Cause 3 — `CULL_DISABLED` on Coplanar Roofs & Kit Meshes (Moderate)
- **File:** [city_materials.gd](file:///Users/kjayap419@apac.comcast.com/Desktop/workspace/test_2/python-Exercise/godot-chennai/src/game_engine/city/city_materials.gd#L64-L74)
- **Code:**
  - `c.roofs.cull_mode = BaseMaterial3D.CULL_DISABLED`
  - `c.kit.cull_mode = BaseMaterial3D.CULL_DISABLED`
  - `c.kit.alpha_antialiasing_mode = BaseMaterial3D.ALPHA_ANTIALIASING_ALPHA_TO_COVERAGE`
- **Why it flickers:** Double-sided roof slabs (`roof_y = upper_top - 0.05` on overlapping multi-part buildings) and double-sided alpha-scissored balcony railings fight both themselves and adjacent wall bands at grazing camera angles.
- **Recommended Fix:** Enforce consistent upward winding on flat roofs (already computed cleanly in `_add_flat`) so `roofs.cull_mode` can return to `CULL_BACK`, and enforce `>= 0.08 m` offset for facade kits.

### Cause 4 — Half-Precision Specular Sparkle on Adreno 613 (Documented)
- **File:** [city_materials.gd](file:///Users/kjayap419@apac.comcast.com/Desktop/workspace/test_2/python-Exercise/godot-chennai/src/game_engine/city/city_materials.gd#L45-L48)
- Decision `G-343` already disables specular on `CityMaterials`, but any third-party or newly imported `.glb` materials that forget `specular_mode = SPECULAR_DISABLED` (or leave metallic reflections bright at roughness < 0.7) will trigger single-pixel shimmer on mid-range Adreno GPUs. Keep `roughness >= 0.85` / low metallic factor for matte plaster and painted surfaces.

### Cause 5 — Near/Far Chunk Boundary & Shadow Cascade Shimmering (Low–Moderate)
- **Files:** [chunk_builder.gd](file:///Users/kjayap419@apac.comcast.com/Desktop/workspace/test_2/python-Exercise/godot-chennai/src/game_engine/city/chunk_builder.gd#L11-L13), [perf_wiring.gd](file:///Users/kjayap419@apac.comcast.com/Desktop/workspace/test_2/python-Exercise/godot-chennai/src/app/perf/perf_wiring.gd#L308-L313)
- `Near` (walls + roofs + kit) and `Far` (one quad per wall + flat roof cap) swap via `ChunkStreamer.near_distance`; if a chunk straddles shadow-map texel edges without snapping or if custom `.glb` replacements overlap an unhidden procedural footprint, double-drawing creates severe flicker.
- **Recommended Rule:** Every replaced OSM `project_building_id` must be skipped inside `BuildingMeshes` in the exact chunk pass before building procedural walls/roofs, mirroring `ChunkBuilder.without_landmark_buildings`.
