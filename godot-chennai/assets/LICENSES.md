# Asset licences (Godot version)

Each agent adds its own section; the coordinator merges them.

## Vehicles, aircraft, trains (Models)

| Files | What | Source | Licence |
|---|---|---|---|
| `vehicles/saloon*.glb`, `suv*`, `coupe*`, `formula*` and their `.json` | Premium cars and the race car | Original, generated by `tools/blender/vehicles/cars.py` (Blender 5.2 LTS) | Original work for this project. No real make, badge, grille, logo, livery or number |
| `aircraft/helicopter*`, `airliner*`, `light_aircraft*` and `.json` | Helicopter, narrow-body airliner, light aircraft | Original, generated by `tools/blender/vehicles/aircraft.py` | Original work for this project. Invented airline colours: no airline name, logo or registration |
| `trains/emu_*`, `emu_ac_*`, `wap7*`, `lhb_coach*`, `vb_*` and `.json` | Chennai suburban EMU and AC EMU, WAP-7-style loco, LHB-style coach, Vande-Bharat-style set | Original, generated by `tools/blender/vehicles/trains.py` | Original work for this project. Real shapes and colour families only: no Indian Railways, metro or train-name logo, no lettering, no real numbers |
| `vehicles/shared/vehicle_palette_*.png` and the textures embedded in the GLBs | Palette atlas and liveries | Generated by the same scripts (`vkit.py`, the livery painters) | Original work for this project |
| `vehicles/hatchback*`, `motorbike*`, `auto_rickshaw*`, `ambulance*`, `bus*` (GLBs copied unchanged; `.json` made by `port_road_vehicles.py`) | Road vehicles of the Three.js game | `chennai-open-world/tools/blender/vehicles.py`, `auto_rickshaw.py` (copied to `tools/blender/vehicles/road/`) | Original work for this project (rows in `chennai-open-world/assets/README.md`). No maker's badges, logos, grilles or liveries; plates are not real registrations |

No reference images were used, as textures or otherwise. Proportions come from published
dimensions of the vehicle classes, so the train and aircraft sizes are estimates.
