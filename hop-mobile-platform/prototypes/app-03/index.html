hop.App concept · 03 · Rider & Captain
Design preview · sample data · no real actions
Verdict

The current colours need to change; the layout and type are good.

Outfit + Inter, the vehicle artwork, bottom sheets and spacing work well and are kept. The palette is the weak point: three competing accents, two of which fail contrast and blend into Google/OSM map tiles.

Current palette — problems

PairContrastIssue

  • Rider (coral) and Captain (yellow) look like two different brands.
  • Coral sits next to SOS/cancel red, so the main action looks like a warning.
  • Olive/sage surfaces look muddy against OSM’s warm beige tiles.

Proposed — one palette for both apps

PairContrast
White on Hop Indigo (buttons)7.2 : 1
Indigo route vs map land6.2 : 1
Ink on white18.2 : 1
Muted on light grey4.6 : 1
White on indigo (dark mode)5.6 : 1
Success / warning / danger badges4.7 – 5.4 : 1
  • Indigo doesn’t appear on Google or OSM maps, so routes and pins always stand out.
  • Green, amber and red are kept for status only: online/paid, expiring, SOS/cancel.
  • Captain is identified by its name, green “Online” state and content, not a second brand colour.

Making Google and OSM maps match

The prototype map is a drawing of the target look. In the live apps, mute the provider tiles so Hop’s indigo route and markers carry the colour.

OpenStreetMap (Leaflet): add a day filter next to the existing night filter in shared/maps/map.css:

.hop-map-canvas .leaflet-tile-pane { filter: saturate(.4) brightness(1.04) contrast(.94); }

Google Maps: add a muted day style in shared/maps/google.ts (see README for the full list), e.g.

{ elementType: "geometry", stylers: [{ color: "#eef0f4" }] },
{ featureType: "road", elementType: "geometry", stylers: [{ color: "#ffffff" }] },
{ featureType: "road.highway", elementType: "geometry", stylers: [{ color: "#e3e5ed" }] },
{ featureType: "water", stylers: [{ color: "#cde0f5" }] },
{ featureType: "poi.park", elementType: "geometry", stylers: [{ color: "#d6ecd8" }] },
{ featureType: "poi.business", stylers: [{ visibility: "off" }] }
Use the menu above each phone or tap through the buttons inside. The live Hop apps are unchanged.
