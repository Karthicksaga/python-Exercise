                                                                                                                                                                                               # Workspace

Only two folders are active. Everything else (`bike-taxi`, `python*`, `oop assignment`) is old exercises; ignore it.

- `hop-mobile-platform/`: Rider and Captain mobile apps (Capacitor + Vite + TypeScript). Read `hop-mobile-platform/CLAUDE.md` before changing anything there.
- `hop-platform/`: the Go API (`backend/`), plus the canonical mobile UI renderer in `prototypes/mobile-first/` that both mobile apps import. Read `hop-platform/CLAUDE.md` for backend work.

UI work on either app also needs the skill `.agents/skills/hop-mobile-design/SKILL.md`.

## Saving tokens
- Large files: `prototypes/mobile-first/app.js` (~150 KB), `style.css` (~3.3k lines) and `shared/design/animations.css` (~1.5k lines). Grep for the selector or function first, then read only that range.
- `node_modules/`, `dist/`, `test-results/`, `playwright-report/`, `evidence/` and `docs/ui-ux-audit-evidence/` are generated output. Never read them.
- API contract summary: `hop-platform/docs/API.md`. Read it instead of the Go handlers when you only need request/response shapes.
- Git: `master` is the main branch. Commit only when asked.
